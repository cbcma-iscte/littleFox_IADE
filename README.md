Little Fox - 3D Prototype
Game developed for IADE (2022)

3D arcade adventure game in third-person view  developed in Unity.

🎮 Core Mechanics 
- **3D Movement and Camera:** The game uses tank-style controls (forward/backward movement) with camera rotation tied to lateral inputs, enabling smooth navigation in a 3D environment.
- **Reactive Artificial Intelligence (AI):** Enemies are programmed with a raycast vision system. Upon detecting the player, the Bear actively pursues them.
- **Complete Game Loop:** Implementation of clear game states, including Win/Loss conditions and a seamless respawn system that resets the player to the origin point upon taking damage.
- **Collision Detection:** A trigger-based hitbox system that accurately detects item collection and enemy encounters.

Environment and character prefabs were sourced from the Unity Asset Store.
